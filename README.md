# GC Infrastructure Lab

Personal infrastructure-as-code lab for developing hands-on experience with Terraform, automation, networking, security, CI/CD, and Canadian public-sector cloud concepts.

## Goals

 - Infrastructure as code
 - Git and GitHub workflows
 - CI/CD with GitHub actions
 - Network segmentation and security
 - Linux and Windows infrastructure
 - Automation and configuration management
 - Cloud governance concepts

## Current Environment

 - Windows 11 Pro / Hyper-V
 - OPNsense firewall
 - Ubuntu Server management VM
 - Isolated management network
 - WSL and VS Code development environment
